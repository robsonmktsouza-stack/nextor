# Arquivo do motor fiscal nativo

O motor NFC-e próprio do Nextor foi retirado do código ativo em 02/10/2026 antes de uso em produção.

Arquivo preservado:

- `archive/nextor-native-nfce-2026-10-02.zip`

O ZIP contém metadados/patches da implementação, snapshots dos arquivos compartilhados e a referência exata do commit Git que preserva o código completo.

O PDV continua funcionando com comprovante interno **sem valor fiscal**. Nenhuma emissão NFC-e é executada pelo Nextor neste estado.

A próxima integração fiscal poderá ser implementada por um adapter separado, sem reativar automaticamente este motor arquivado.
